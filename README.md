# Rivas Project 1 — Salon Booking Platform

Monorepo containing:
- **Laravel API backend** (this root folder)
- **Frontend** (vanilla JS + Konva editor) in [`Reserv/`](./Reserv/README.md) — see that folder's own README for frontend setup

This README covers the backend. For the frontend, go to `Reserv/README.md`.

## Requirements

- PHP 8.4+
- Composer
- MySQL 8+ (or MariaDB)
- Node.js 18+ (needed for the frontend, see `Reserv/`)

## 1. Clone the project

```bash
git clone <repo-url>
cd rivas-project1
```

This single clone gets you both the backend (root) and frontend (`Reserv/`).

## 2. Backend setup

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan jwt:secret
```

Open `.env` and set:

```dotenv
APP_URL=http://localhost:8000
FRONTEND_URL=http://localhost:5174        # URL of the Reserv dev server

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_local_db_name
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password

SANCTUM_STATEFUL_DOMAINS="localhost:5174,127.0.0.1:5174,localhost,127.0.0.1"
```

> `JWT_SECRET` is generated by the `php artisan jwt:secret` command above — never copy someone else's value.

## 3. Database

Create the database in MySQL (name must match `DB_DATABASE`), then:

```bash
php artisan migrate
php artisan db:seed
```

This runs all seeders (`CategorySeeder`, `SalonSeeder`, `SectionSeeder`, `PermissionSeeder`, etc.) to get sample data.

## 4. Run the backend

```bash
php artisan serve
```

Runs on `http://localhost:8000` by default (matches `APP_URL`).

## 5. Run the frontend

See [`Reserv/README.md`](./Reserv/README.md) — it needs the backend running first.

## CORS / cookies

- CORS origins are configured in `config/cors.php`, restricted to `localhost`/`127.0.0.1` for local dev.
- Auth uses HTTP-only cookies (`access_token` / `refresh_token`) — the frontend must send requests with `credentials: 'include'`.

## Common issues

| Symptom | Likely cause |
|---|---|
| CORS error in browser console | Check `config/cors.php`, and make sure the failing route returns JSON (not a `redirect()`) |
| Redirected to `/login` unexpectedly | `access_token` cookie expired and `refresh_token` missing/expired — log in again |
| `SQLSTATE[HY000] [1049] Unknown database` | Create the database manually in MySQL before running migrations |

## Tech stack

- Laravel (PHP), MySQL
- `tymon/jwt-auth` for JWT authentication (cookie-based)
- Frontend: vanilla JS, HTML/CSS, Konva.js, Vite (see `Reserv/`)
